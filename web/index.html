Controle

O controlador PI aquece com as lâmpadas e a manta e, se a câmara passar do alvo, liga o cooler para jogar o ar quente para fora.

Simulação

Estes controles mudam o modelo físico, não o firmware. Use para mostrar como o controle reage.
